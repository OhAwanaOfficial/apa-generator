APA Book Reference Format

The basic APA book reference format is:

Author Last Name, First Initial. (Year). Book title in sentence case. Publisher.

APA Book Reference Examples

Single Author Book

Smith, J. (2020). Introduction to psychology. Oxford University Press.

Multiple Authors

For two authors, list both separated by a comma:

Smith, J., Johnson, A. (2019). Principles of economics. Pearson.

For three or more authors, list all authors separated by commas:

Smith, J., Johnson, A., Brown, K. (2021). Modern biology. McGraw-Hill.

No Author

When no author is listed, move the book title to the author position:

Merriam-Webster's collegiate dictionary. (2005). Merriam-Webster.

What to Include in an APA Book Reference

Every APA book reference citation needs these four elements:

  • Author — Last name followed by first initial. Example: Smith, J.
  • Year — Publication year in parentheses. Example: (2020).
  • Title — Book title in italics, sentence case only. Example: Introduction to psychology.
  • Publisher — Publisher name without location. Example: Oxford University Press.

APA Book Reference vs In-Text Citation

The full APA book reference goes in your reference list at the end of your paper. The in-text citation is a short version placed inside your text where you use the source.

Reference list entry:

Smith, J. (2020). Introduction to psychology. Oxford University Press.

In-text citation:

(Smith, 2020)

Common Mistakes to Avoid

  • Capitalizing every word in the title — APA uses sentence case. Only capitalize the first word and proper nouns.
  • Wrong author format — Always use Last Name, First Initial. Not full first name.
  • Missing publisher — Always include the publisher name for book references.
  • Using location before publisher — APA 7th edition removed the city/location requirement.
