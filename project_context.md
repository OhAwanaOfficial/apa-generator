## ⚙️ Core Functionality

### JS Logic
- `formatAuthors()` → formats author names into APA style
- `formatTitle()` → converts title to sentence case
- `generateAPA()` → generates citation based on type:
  - book
  - website
  - journal

### Output Format Example
Smith, J. (2020). Test book.
